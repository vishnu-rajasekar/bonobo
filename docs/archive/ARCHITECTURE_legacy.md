# Architecture

Panther is a layered structural generation engine.

Layer 1 — Canonical Graph
Layer 2 — Grammar (state transitions)
Layer 3 — Evaluator (physics semantics)
Layer 4 — Learning (policy over grammar)

Diversity and goal steering operate above evaluator layer.
